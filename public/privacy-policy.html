Política de Privacidade — Shape Express

Última atualização:

O Shape Express ("nós", "nosso") opera o aplicativo móvel Shape Express. Esta página informa sobre nossas políticas de coleta, uso e divulgação de dados pessoais.

Dados Coletados

  • Dados de conta: nome, e-mail e tipo de usuário (atleta ou treinador), fornecidos no cadastro via Firebase Authentication.
  • Dados de treino: treinos, séries, repetições e progresso registrados pelo usuário.
  • Dados de pagamento: processados pelo Stripe. Não armazenamos dados de cartão.
  • Mensagens de chat: armazenadas no Firestore para comunicação entre atletas e treinadores.
  • Dados de uso: logs de acesso para diagnóstico de erros (sem dados pessoais identificáveis).

Uso dos Dados

Os dados são usados exclusivamente para:

  • Fornecer e melhorar os serviços do aplicativo;
  • Processar pagamentos de planos e serviços;
  • Permitir comunicação entre atletas e treinadores;
  • Gerar recomendações de treino via IA (Google Gemini).

Compartilhamento de Dados

Não vendemos dados pessoais. Compartilhamos apenas com provedores de serviço necessários para o funcionamento do app (Firebase, Stripe, Google Gemini), sob acordos de confidencialidade.

Segurança

Utilizamos autenticação Firebase, HTTPS em todas as comunicações e regras de segurança no Firestore para proteger seus dados.
